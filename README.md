Tiles Gallery
📌 Project Overview

Tiles Gallery is a modern, responsive web application built with Next.js (App Router) that showcases a collection of tiles. Users can explore different tile designs, view detailed information, and manage their profiles with authentication.

Live URL :https://tiles-gallery-beryl.vercel.app

 Purpose

The goal of this project is to create a visually appealing and functional tile gallery platform where users can:

Browse tiles
Search for designs
View detailed information
Manage their profile

Key Features

Layout & Navigation
Responsive Navbar with Logo, Links, and Auth Buttons
Footer with social links & contact section

Home Page
Hero Banner with CTA (Browse Now)
Marquee (scrolling updates)
Featured Tiles (Top 4 from server)

All Tiles Page
Search tiles by title
Grid layout with tile cards
Navigate to details page

Tile Details Page
High-quality tile image
Full information (title, description, tags, etc.)

Authentication (BetterAuth + MongoDB)

Email & Password Login
User Registration
Google Social Login
Error handling with toast/messages

 My Profile (Private Route)
View user information
Update Name & Profile Image
